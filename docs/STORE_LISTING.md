# Chrome Web Store 掲載文案

## 短い説明

HSコード検索・FTA/EPA比較・削減額の概算。収録データと参考推定を分けて表示する無料の貿易調査支援ツール。

## 詳細説明

TariffScopeは、輸出入に関わる担当者がHSコードとFTA/EPA活用の初期調査を素早く進めるためのChrome拡張機能です。

品目名やHSコードから候補を検索し、輸出国・輸入国・貿易金額を入力すると、利用可能なFTA/EPA協定、関税率、削減額の概算を比較できます。結果には収録済みの税率データと参考推定を分けて表示するため、どこまでが確認済みデータかを把握しながら調査できます。

推奨協定については原産地規則ガイドも表示します。必要書類や証明方式を確認できるので、通関士や社内担当者へ相談する前の整理に役立ちます。

## 主な機能

- HSコード検索: 日本語・英語の商品名、コード番号で検索
- FTA/EPA比較: RCEP、CPTPP、日EU EPA、日英EPA、日豪EPAなどを比較
- 削減額シミュレーション: 貿易金額から関税削減額を概算
- データ根拠表示: 収録データと参考推定を明示
- 原産地規則ガイド: 証明方式、必要書類、主な確認事項を表示
- Webページ上のHSコード検出: 貿易関連サイトでHSコードをハイライト
- 検索履歴: 過去の検索条件を保存して再利用
- エクスポート: CSVダウンロード、クリップボードコピー
- ローカル処理: 検索条件や貿易額を外部送信しない

## こんな方におすすめ

- FTA/EPAを活用できるか最初に確認したい貿易担当者
- HSコード候補を短時間で探したい中小企業の輸出入担当者
- 協定ごとの削減効果を社内検討用に概算したい方
- JETRO、税関、協定文書を確認する前に調査対象を絞り込みたい方

## 注意事項

TariffScopeで提供される関税率、協定情報、原産地規則情報は参考情報です。実際の申告、契約、価格決定、原産地証明では、必ず税関、通関士、JETRO、各協定文書などの公式情報を確認してください。

一部の組み合わせでは税率データが未収録のため、参考推定として表示されます。参考推定は調査の優先順位を決めるための補助情報であり、実務判断には使用しないでください。

## プライバシー

TariffScopeは個人を特定できる情報を収集しません。検索履歴、貿易金額、設定情報はユーザーのブラウザ内に保存され、外部サーバーへ送信されません。
