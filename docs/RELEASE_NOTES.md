# TariffScope リリースノート

このリリースノートは、利用者が「何が便利になったのか」「自分の業務に影響があるのか」をすぐ理解できるように、技術的な変更よりも利用シーンを中心にまとめます。

## v1.3.1

### データの再読み込みを安定させました

データ読み込みに一度失敗した場合でも、次の操作で再試行できるようにしました。手動でデータを再読み込みした際は、取得したデータをそのまま利用するため、不要な再読み込みも減らしています。

### 検索履歴の保存処理を整理しました

ポップアップとバックグラウンドで分かれていた検索履歴の保存処理を一本化しました。以前の保存形式で残っている履歴も、新しい保存先へ引き継ぎます。

### データ更新時のフォールバックを改善しました

オンライン更新を利用する構成では最新データを優先し、取得できない場合は拡張機能に同梱されたデータへ戻るようにしました。オフライン時や一時的な通信障害でも、調査を続けやすくしています。

### 内部品質を改善しました

データ取得、キャッシュ、ストレージ、メッセージ処理の責務を分離し、自動テストを拡充しました。利用者向けの操作方法は変わりません。

## v1.3.0

### 商品説明からHSコードの検索語を作れるようになりました

Chrome内蔵AI（Gemini Nano）に商品説明を入力すると、HSコード候補を探すための日本語・英語キーワード、素材、用途、確認観点を整理できます。生成した検索語は既存のHSコード検索へ渡されるため、分類調査の初動を短縮できます。

### 商品説明は端末内で処理されます

Chrome内蔵AI検索補助で入力した商品説明は、対応Chromeの端末内モデルで処理されます。本拡張機能から外部LLMサービスへ商品説明を送信することはありません。初回利用時はモデルの準備に時間がかかる場合があります。

### 最終的な分類判断は引き続き公式確認が必要です

Chrome内蔵AIはHSコードや関税率を断定せず、候補検索に使う語句の整理だけを行います。実際の申告や契約では、税関、通関士、JETRO、品目表などの公式情報を確認してください。

## v1.2.3

### データの出典と適用範囲を確認しやすくなりました

結果画面、CSV出力、コピー内容に、データ出典、検証日、適用範囲を追加しました。検索結果を社内共有したあとでも、どの参考データに基づく結果なのかを確認しやすくなりました。

### 収録データの状態がわかりやすくなりました

収録データパネルに、同梱データの出典、最終検証日、適用範囲を表示するようにしました。オンライン更新元が未設定の場合も、その状態を明確に確認できます。

### テスト実行環境を安定させました

ローカル環境でもテストを再現しやすいように、JestのTypeScript変換設定を見直しました。アプリの機能変更を安全に確認しやすくしています。

## v1.2.2

### データの根拠が見やすくなりました

関税率の表示に「収録データ」と「参考推定」の区分を追加しました。これにより、結果画面でどの税率が同梱データに基づくものか、どの税率が未収録データを補う参考値なのかを確認しやすくなりました。

### 推奨協定の表示がより慎重になりました

収録済みの税率データがある協定を優先して推奨するようにしました。参考推定しかない場合は「参考候補」として表示し、実務判断には公式情報の確認が必要であることを明確にしました。

### EU向け・EU発の調査がしやすくなりました

国選択にEU加盟国を追加し、EUを選択した場合も収録済みの加盟国データを使って照合できるようにしました。日EU EPAの確認を始めやすくなりました。

### 収録データ数の表示を実データに合わせました

アプリ内の収録データ表示を、実際の同梱データ件数に合わせました。現在の収録範囲はHSコード88件、FTA/EPA協定20件、関税率75件です。

### ストア説明とドキュメントをわかりやすくしました

TariffScopeでできることを「公式確認前の事前調査を短くするツール」として整理しました。あわせて、関税率や原産地規則は参考情報であり、最終判断では税関・通関士・JETRO等の公式情報を確認する必要があることを明記しました。

## 利用者へのお願い

TariffScopeの結果は、FTA/EPA活用の可能性を素早く確認するための参考情報です。実際の申告、契約、価格決定、原産地証明では、必ず税関、通関士、JETRO、各協定文書などの公式情報を確認してください。
